# ラブリィメモリー

**太陽と踊れ月夜に唄え（Second Season）** のライブのセットリストを記録・集計する、非公式のファンサイトです。

👉 **https://lovely-memory.pages.dev/**

サイト名は 2期曲「ラブリィフェリス」から。

## 見られるもの

### 楽曲

- 曲ごとの歌唱回数と**歌唱率**（初披露以降の公演のうち、歌われた公演の割合）
- 初披露日、最後に歌われた日、最後に歌われてから何日経ったか
- 単独公演・対バン・リリイベ・フリーライブなど、公演の種別で絞り込み
- 曲のページでは、歌唱履歴、初披露以降の出現パターン、1 曲目・ラストになった回数

### 公演

- 2026 年 9 月 4 日の Second Season デビュー以降の全公演と、そのセトリ
- 初披露の曲、欠席メンバー、複数ステージ（フェスの各会場など）
- セトリ告知ポストとイベンターノートへのリンク

### メンバー

- 出演率と、欠席した公演の一覧
- 参加した歌唱の数

### カバー曲・コラボステージ

- カバー曲は原曲の情報とあわせて、歌われた公演を一覧で表示
- 他グループとのコラボステージ（メンバー個人での参加）は、楽曲の集計からは既定で外しています（切り替え可能）

## データについて

| 内容 | 出典 | 更新 |
|---|---|---|
| 公演（日時・会場・出演者） | [イベンターノート](https://www.eventernote.com/actors/72524) | 毎日自動 |
| セトリ | 公式 X（[@taiyototsukiyo](https://x.com/taiyototsukiyo)）のセトリ告知 | 公演当日〜翌日に手動で登録 |
| 楽曲・作詞作曲 | [公式サイト](https://taiyotsukiyo.com/discography/) | 新曲発表時 |

- **出演メンバー**はイベンターノートの出演者情報をもとにしています。登録が漏れている場合があります。
- **初披露**は、このサイトに記録しているセトリの中で最初に歌われた公演です。1 期曲の場合は「2 期で最初に歌われた公演」になります。
- セトリの告知が無い公演は集計に含まれません。

## 間違いを見つけたら

セトリや出演メンバーの誤り、抜けている公演などがあれば、[Issue](https://github.com/Ronny-zzl/lovely-memory/issues/new) でお気軽にお知らせください。
